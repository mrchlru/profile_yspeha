# Переменные окружения (админ-панель DriveS)

Подробные инструкции для разработчиков и деплоя. В интерфейсе «Настройки» показываются только статусы и короткие подписи.

## Доступ в админ-панель

| Переменная | Назначение |
|---|---|
| `ADMIN_PANEL_EMAIL` | Почта главного администратора |
| `ADMIN_PANEL_PASSWORD` | Пароль главного администратора |

Изменение — только в конфигурации сервера (Timeweb Cloud / `.env`), не из UI.

## OpenAI

| Переменная | Назначение |
|---|---|
| `OPENAI_API_KEY` | Ключ API |
| `OPENAI_BASE_URL` | Необязательный relay или прокси |
| `OPENAI_RELAY_SECRET` | Секрет для relay, если используется |
| `OPENAI_MODEL` | Модель для отчётов и заключений |
| `OPENAI_MANAGER_BRIEF_MODEL` | Модель кратких заключений для руководителей |

## Google Таблицы

| Переменная | Назначение |
|---|---|
| `GOOGLE_SHEETS_SPREADSHEET_ID` | ID таблицы выгрузки |
| `GOOGLE_SERVICE_ACCOUNT_JSON` | JSON сервисного аккаунта (одной строкой) |

Таблицу нужно расшарить на `client_email` из JSON с правом «Редактор».

## Уведомления о выгорании (опционально)

| Переменная | Назначение |
|---|---|
| `CRON_SECRET` | Секрет для `GET /api/cron/burnout-reminders` |
| SMTP / почта | Настраивается на сервере (отдельно от UI) |

Напоминания также отправляются при работе в админ-панели без внешнего cron.

## Прочее

См. `.env.example` в каталоге `web/` при наличии.
